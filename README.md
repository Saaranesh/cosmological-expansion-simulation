# cosmological-expansion-simulation
Compare the evolution and the expansion of two different universes, side-by-side, that have different compositions of dark energy.

This program is designed for 3.10+. To set up the necessary environment, ensure the following libraries are installed:
 - numpy, for simple numerical and mathematical operations
 - matplotlib, to manage the rendering of the simulation and the plotting of the graph
 - scipy, for an evaluator of the hubble parameter/ friedmann integrals

These dependencies can be installed via pip:
  pip install numpy scipy matplotlib

Then, simply insert the program and run the script in this environment. The parameters of the cosmological models (i.e. H0, Om0, Ode0) can be modified within the code. This allows comparative analysis of the expansions and evolutions of different cosmological models and universes.
